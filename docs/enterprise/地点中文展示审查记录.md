# 地点中文展示审查记录

> 日期：2026-10-21｜范围：P3.1e3c｜数据文件：`data/fixtures/reviewed_place_display_v1.psv`

## 审查方法与结果

原始 `reviewed_places_v1.psv`、`reviewed_places_v2.psv` 保持原样。按稳定地点 ID 将中文展示名、展示主题、名称证据地址、证据类型、审查日期和必要的中文简介修订放在独立表中。应用启动读取时验证 190 个 ID 一对一对应、95 城市各 2 条、名称含中文字符、证据地址为公开 HTTPS、主题有效、日期不过期且同城展示名不重复。任一条校验失败，整份展示表不会产生部分推荐。

| 名称证据类型 | 条数 | 用途与限制 |
| --- | ---: | --- |
| 原目录已审中文别名 | 59 | 保留原有同一地点别名；豫园另以城市文旅资料复核主题。 |
| 中文百科条目 | 48 | 核对名称、场馆和城市；不是开放时间或价格的实时依据。 |
| 场馆／城市／公共机构中文资料 | 15 | 优先采用同一具体场馆的中文称呼。 |
| 中外文同页的二级资料 | 68 | 只作为译名对照；地点存在性和城市仍由原目录来源与地理校验约束。这一组适合后续逐步替换为官方中文来源。 |

合计 **190 个地点／95 个可达城市**均有中文展示名和名称对照地址。原名、原目录来源、原审查时间及地点 ID 继续保留。检索摘要和模型只帮助发现候选，不直接写入旅客答复；本次审查后的表是静态版本，不会在运行时自动改写。

## 重点修订

- [上海文旅资料](https://lycx.whlyj.sh.gov.cn/c/scenicArea.view.ac?id=24845)用于将豫园的展示主主题从 `nature` 调为 `culture`，正文改为“古典园林与地方文化”。原目录类别保留作对照。
- [名古屋旅游官方网站](https://www.nagoya-info.jp/zhcn/spot/detail/14/)与其[中文旅游资料](https://www.nagoya-info.jp/upload/pamphlets/origin/204694081966221f015ddbb.pdf)核对“德川美术馆”“名古屋城”；[普吉岛地点资料](https://zh.wikipedia.org/wiki/%E6%B0%B4%E7%A2%93%E6%96%97%E6%AF%8D%E5%AE%AE)核对“水碓斗母宫”，替换不可靠的直译。
- [达拉斯旅游局中文页](https://www.visitdallas.com/zh/directory/dallas-museum-of-art/)、[亚特兰大旅游中文页](https://discoveratlanta.com/zh/%E7%8E%A9%E4%B9%90%E6%94%BB%E7%95%A5/)、[南越王博物院报道](https://www.nywmuseum.org.cn/News/Details/yfzx?nid=12458)分别核对达拉斯艺术博物馆、佐治亚水族馆和西哈努克吴哥博物馆。其他每条名称证据在数据表中逐项记录。
- 中文正文显示“中文名（原名）”；页面引用也以中文名为主，但 API 的 `place` 和 `title` 仍是原名，另增 `display_name`。同一地点的中文名或原名可帮助解析后续追问，不会改变地点 ID 或交易权限。

## 边界与后续审阅

这批来源用于**名称与主题**核对，不能推断门票、营业时间、天气、距离、交通或实时营业状态。68 条二级资料的长期维护质量低于官方中文资料；后续如发现译名冲突，应在新版审查表中按 ID 纠正并重新回归，不能通过模型即席改名。主题沿用原目录的人工标签，除豫园外本次没有凭英文词缀批量改动；自然历史博物馆等跨主题地点仍可在未来专题审查中细化。

本步不包含正式 PostgreSQL 页面完整旅程与服务重启验收，也不代表所有地点对任意偏好都有匹配结果。正式发布前仍需按独立计划完成整段体验和来源抽查。
