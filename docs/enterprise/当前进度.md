## 4. 当前优先风险

1. 旧 Python 源码中的硬编码凭证已移除；`config/development.yml` 是被 Git 忽略的旧本机文件，可能仍有敏感值。所有者需核对并在服务商后台轮换仍有效的密钥，分享整个项目目录前也须检查该文件。
2. 当前客户端传入旅客／会话标识，存在跨账号访问风险；新身份链路必须先建立。
3. 旧酒店 `booked` 字段不是旅客订单模型；P0 的 `demo_source` 只是暂存数据，正式订单与旅客授权在 P1 建立。
4. 当前确认是通用文本恢复，不能证明确认者、动作内容与执行结果的一致性。
5. 本机未安装可用的 Docker／WSL，PostgreSQL 导入脚本尚未执行；模型调用也未实测。当前健康检查不等于交易闭环验收。
