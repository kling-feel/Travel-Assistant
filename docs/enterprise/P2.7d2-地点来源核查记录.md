# P2.7d2 地点来源核查记录

> 核查日期：2026-10-20｜范围：新增 65 座可达城市、130 个地点。第一版的 30 城市、60 条保持原内容与顺序。

## 范围和方法

从只读航线样本的 `Scheduled` 到达航班取得 **95** 座可达城市，与第一版目录比较得到缺口 **65** 座；机场资料虽列有 106 座城市，其中 11 座没有对应可达航班，不纳入推荐目录。按 22、22、21 城市分三批，每城选两个具体、位于目标城市的地点。130 个新来源页面均尝试逐页打开，并核对页面所指地点、城市／国家及简短介绍的主题；不能打开或地点落在邻市的候选予以更换。来源分类按实际使用页面标注，不把百科标成官网。

第二版共 **190 条／95 城市**，每城恰好两条；新增条目中场馆官网 **28**、城市或公共机构 **5**、可核查百科 **97**。连同第一版，全部目录为场馆官网 **49**、城市或公共机构 **14**、百科 **127**。每条完整来源 URL、类别及审查日直接保存在 [第二版目录](../../data/fixtures/reviewed_places_v2.psv)，第一版保留作版本核对。页面访问成功只证明本次能检查静态地点事实，不保证网页长期可用，也不证明票价、营业时间、距离或服务实时状态。

## 入库与使用边界

- 加载时按字段、稳定 ID、城市／国家代码、重复地点、HTTPS 来源域名、分类、审查日和可达城市全集校验；任一记录不合格即拒绝整份目录。第二版前 60 条须与第一版逐条一致，防止扩展时悄悄改写旧资料。
- 目录只包含地点名称、短介绍、主题、别名和来源元数据。地点推荐答复只选当前可达城市、符合主题且审查未超过 180 天的目录条目；不从原网页正文直接生成交易事实。无证据时对票价、酒店距离和实时安排明确说明不能核实。
- 阿里云 `GlobalBasic` 本小步 **0/180 次新增调用**；逐页来源核查通过公开页面完成。实时联网开关继续关闭，后续启用须单独验收来源质量、费用、失败回退与安全边界。网址作为 API 结构化来源字段保留，答复正文不强制展示链接。
- 本次 25 组真实 DeepSeek 双轮隔离抽测均通过。首次受限环境网络连接失败已预记为一次尝试且无完整用量；获准网络环境恢复后完成 25 次可计量请求，累计 **26/30 次尝试**，输入 23,303、输出 6,409 tokens；估算 0.066528 元，全部输入按未缓存计的保守值 0.097878 元。实际金额以 DeepSeek 账单为准。没有从本次测试向阿里云发送请求。

## 后续维护

目录事实的人工审查期为 180 天；过期条目自动停止用于推荐。维护时重新打开原来源、核对地点仍在目标城市及简短介绍仍成立，记录新的审查日期并运行全量校验。若来源失效或相互冲突，先撤下对应地点并补可核查来源；不以模型猜测补齐。
