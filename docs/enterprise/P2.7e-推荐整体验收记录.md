# P2.7e 推荐整体验收记录

> 验收日期：2026-10-20｜结论：**人工目录模式通过；实时搜索不建议默认开启。** 本记录不代表本机主线或 GitHub 已发布。

## 离线全城与边界

从只读航线样本枚举 95 座有 `Scheduled` 到达航班的城市。隔离内存 API 为每城建立模拟航班，逐城以英文和中文别名各查询一次：两种说法均返回同城、同国家代码的 **2 条**目录来源，答复正文不含原始 URL。目录总计 190 条、每城恰好两条；第一版 60 条的内容和顺序保持不变。11 座不在当前演示航班可达范围的机场城市不入目录；同名异国城市、无匹配主题、过期审查日期均按预期拒绝或降级。

本轮补齐了“今天几点开门／营业时间”的无证据提示：目录没有实时营业安排，答复明确要求以场馆官方信息为准；票价和酒店距离继续分别按缺少票价、可信坐标降级。固定回归验证实时搜索超时或返回带指令文字的候选时，只能输出人工目录已有地点，并提示回退；不能生成游览交易卡。

## 阿里云 GlobalBasic 隔离抽查

仅在隔离评估脚本中对公开的城市、国家和主题发起搜索；正式配置 `ALIYUN_IQS_ENABLED=false` 未改变。覆盖中国与亚洲其他地区、欧洲、美洲、非洲、中东及大洋洲共 **18/60 次**预记请求，均无认证、限流或接口错误。每次最多看 12 条搜索候选，共 **216 个候选位置**；适配器接受 33 条，涉及 14 次查询。只有 **2/18 次查询**出现与当前目录地点名称的精确匹配。该指标不计不同语言、冠词和上级场馆名称的语义等价，因此只能衡量当前代码能直接利用的匹配，不能作为搜索引擎整体召回率。

对 33 条被接受的候选页面均尝试打开核对。部分页面可读且指向真实地点，例如 [东京国立博物馆](https://www.tnm.jp/?lang=en)、[上海中华艺术宫的市政府介绍](https://english.shanghai.gov.cn/en-MuseumsGalleries/20241018/dfda779aa5f644f48f99e89ffb745703.html)、[罗马国家博物馆官网](https://museonazionaleromano.it/en/)；但这些结果没有进入当前经人工审查的地点目录，也不会给旅客增加新事实。另有页面打开失败或被拒绝；被接受的标题中出现 [学术文章](https://www.tandfonline.com/doi/full/10.1080/13527258.2020.1799060)、[画廊清单](https://zhuanlan.zhihu.com/p/676561775)、[政府机构介绍](https://www.waimaoribao.com/baike/68839.html)和泛化的“画廊”等，不满足具体经典地点的准入要求。18 次请求耗时中位数约 **3.13 秒**。

由于已有目录覆盖全部 95 座城市，而当前实时搜索不能稳定给出可利用、可读且准确匹配的补充信息，继续扩大付费抽查的收益低。依照计划中的来源污染停机条件，在 18 次后停止。`GlobalBasic` 专属单价仍未显示，**实际搜索费用只能以阿里云账单核对**，不按其他引擎价格推算。

## 真实 DeepSeek 隔离对话

独立内存 API 执行 16 个场景轮次，累计 **15/15 次**真实模型调用；真实航司政策场景由确定性边界处理，无需模型调用。覆盖跨城改问、搜索超时回退、票价／营业时间／酒店距离、虚构与真实政策分流、景点预订拒绝，以及航班预订／改签／取消、酒店预订／取消、租车预订／改期提案。同请求重放结果一致，跨账号会话访问被拒；所有业务卡均停留在待确认状态，三类订单各保持原有 1 笔，未发生交易确认。

首轮两组租车输入把 2026-10-25 和 2026-10-29 的瑞士当地中午误写为 `+02:00`，服务端正确拒绝并提示机场时区不符；改为当天正确的 `+01:00` 后，两组真实模型定向复测均生成对应卡。**未解决的业务失败为 0**。共有 7 张有效业务提案卡，0 张游览卡，未观察到密钥输出。账本记录输入 12,961、输出 3,174 tokens；按现有计价假设估算 **0.032253 元**，全部输入按未缓存计的保守值 **0.051314 元**，实际金额以 DeepSeek 账单为准。原始报告和账本保存在 Git 忽略目录，不随项目发布。

最终 **103 项**自动化测试、2026-10-17／2026-11-01 两个演示日期全航线校验、编译、`pip check`、17 条旅客 API 路由与旧图／管理路由 0 条均通过。本轮只改推荐答复的无证据提示和评估测试，没有迁移或持久化会话路径改动；Docker 没有运行中容器，正式数据库未配置连接，所以没有执行 PostgreSQL 重启回归。正式演示库与原 SQLite 未修改。

## 发布建议

建议将 P2.7 以**人工核查目录、实时搜索默认关闭**的模式视为功能分支验收通过。目录来源 URL 和审查日保留在 API `references`，并在超过 180 天后自动停止推荐；维护者需定期重查失效来源。`GlobalBasic` 适配器保留为实验能力，不在演示或部署默认环境开启。功能分支公开发布前，仍须按独立主线发布计划清理最新文件树中的开发工具品牌字样、复核远端差异和密钥，再合并本机 `main` 并同步 GitHub。
