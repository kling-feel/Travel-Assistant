# P3.1：旅客操作页面与本机闭环操作计划

> 编写日期：2026-10-20｜状态：用户已确认，功能分支实施中；本计划只允许在功能分支实现与验收，不授权合并本机 `main` 或推送 GitHub。

## 1. 本阶段交付

在现有 FastAPI 项目内提供一个中文、简洁、适配桌面和窄屏的旅客页面，从本机 `/app` 打开。页面能完成演示账号登录、本人会话与对话、航班／酒店／租车候选只读查询、本人行程、待确认卡逐笔确认或拒绝、操作结果与历史。推荐地点只显示在对话中；不做游览产品浏览和游览交易。页面与 API 同源运行，无外部前端服务、CDN 或大型框架，保留现有 Python 分层和交易服务。

建议使用 `static/` 下的 HTML、CSS、少量原生 JavaScript，加一个仅返回页面的 FastAPI 路由。继续使用现有 Bearer 登录 API；令牌只保留在当前页面的内存中，退出或刷新时清除，刷新后重新登录并从 PostgreSQL 读取原会话。这个取舍避免将令牌长期写入浏览器存储，但刷新需重新登录；若将来要保持登录，再单独设计安全 Cookie 与 CSRF 方案。

## 2. 实施顺序

1. **开工核验与隔离**：重读三份核心文档、本计划和已确认的发布规则；确认本机及远端 `main`、工作区干净、恢复引用与当前数据库容器状态。从已发布的干净 `main` 建 `feature/p31-traveler-ui`，先提交获确认的计划与开工记录。检查本机 `.env` 仅确认所需项存在，不打印密钥。现有正式演示库不重置；需要真实页面联调时优先使用独立的虚构测试库，并在任何数据写入前备份、核验基线。
2. **页面和只读契约**：增加 `/app` 与同源静态资源，明确“虚构平台／模拟交易／无真实付款”。页面打开时先显示登录；登录后显示旅客身份、会话列表、历史消息、本人行程与动作历史。现有 API 没有直接返回演示基准日，增加一个只读、认证后的 `GET /api/v1/demo-state`，提供演示日期与可搜索日期窗，避免页面按电脑当前日期猜测。此步骤不改订单表、交易规则或已应用迁移。
3. **对话与候选查询**：会话可新建、切换、恢复；发言调用 `/sessions/{id}/turns`，每次新问题生成请求键，网络超时重试同一内容时复用该键，避免重复建卡。答复与候选引用按服务端结果显示。另设航班、酒店、租车的只读搜索表单，使用现有分页/排序参数；搜索结果只供旅客查看并在对话中指定，不从浏览器直接构造交易提案。推荐正文按现有对话呈现，页面不强制展示外部链接，API 引用仍可核查。
4. **逐笔交易交互**：对话生成的每张卡分别展示动作类型、对象、前后变化、当地时间、模拟补退金额、规则 ID／版本、有效期与状态。点击确认或拒绝前，先重新读取指定动作详情；仅当仍为 `pending` 时弹出含完整摘要的独立确认框，按钮只提交该动作 ID，不发送浏览器自算的价格、订单或旅客 ID。提交期间禁用重复点击；成功后刷新该卡、本人行程与历史。两张卡没有“一键全部确认”。过期、409 冲突、401 失效、422 输入错误和 503 模型／数据库不可用均显示明确状态，不把失败写成成功。
5. **安全与可用性**：所有模型答复、用户输入、产品名和来源文本用安全 DOM 文本节点呈现，不执行 HTML；脚本／样式只从同源加载，页面增加合适的内容安全与防嗅探响应头。令牌不进入 URL、日志、浏览器长期存储或错误提示；切换账号清空前一个账号的页面数据与待处理请求。表单提供标签、焦点反馈、加载状态和窄屏布局。前端不复制或绕过服务端确认规则。
6. **验收、记录与下一门槛**：运行原有完整自动化测试、两日期全航线校验、编译和依赖检查；补针对页面路由与登录状态的必要测试，并用浏览器真实操作核查布局和交互。以独立虚构 PostgreSQL 数据完成两账号隔离、“改签＋订酒店”双卡独立确认、拒绝／过期／重复点击、刷新后重登恢复会话、推荐有据和无模型时降级。若本机有效 DeepSeek 密钥可用，建议最多 12 次真实模型请求、预算上限 2 元用于页面链路抽测；无可用密钥时只完成固定模型验收，并明确记录真实页面链路未验收。实时搜索保持关闭，不进行付费检索。将实际结果、测试和遗留问题写入《当前进度》，更新 README 使用步骤；功能分支提交后另拟 G-16 合并与 GitHub 同步计划，待用户单独确认。

## 3. 验收门槛

- 本机页面能从登录走到对话、候选查询、两张独立待确认卡和本人订单结果；页面显示与 API 返回一致，未确认卡不改变订单。
- 不同演示账号看不到对方会话、卡片与订单；登出、令牌失效和账号切换不残留上个账号数据。
- 推荐只读，地点介绍不编造票价、开放时间或距离；页面不出现游览交易按钮，实时联网默认关闭。
- 对话重试复用请求键；确认／拒绝只作用于选中的动作 ID，重复点击、失效卡和服务错误都能安全恢复或明确提示。
- 不新增数据库迁移，不触碰正式演示库或原虚构 SQLite；新增文件不含密钥、真实个人数据、旧开发工具字样或本机绝对路径。
