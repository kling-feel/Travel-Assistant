## 当前安全状态与完成标准

- 云端数据库健康、修复版应用在**私有入口健康**，公网代理已关闭；五个原数据卷、旧镜像回退点、证书和可解密的本机加密备份保留。P3.4c3c1c 已核对原订单仍为机票／酒店／租车 2／2／0、供给 33,121 班，公开 HTTPS 登录页 200、未登录本人接口 401。随后临时账号创建命令因服务器 Compose 不支持所传参数而退出；已只读核对**没有创建账号或凭证文件**，没有发业务对话，代理关闭后应用和数据库仍健康。
- **可用部署验收通过**需在正式云端原项目上证明：现有授权账号登录并能看到本人有效行程；临时账号 A/B 能登录，不能读取对方会话与卡片；约 10～12 轮真实 DeepSeek 对话覆盖多轮上下文、只读查询、航班／酒店／租车候选、明确预订、平台政策与联网地点推荐；“先别下单”绝不出新卡，明确选定后才出逐笔待确认卡；**不点击确认／放弃，不改变任何业务订单**；授权后的页面可读、无卡片串会话或明显布局错误；应用资源稳定、日志不泄漏凭证。通过后 HTTPS 网站保持在线，只有已授权账号可进入业务页。
- 模型和联网搜索使用现有云端配置，正常记账；本步不设金额自动停机线。若遇到明确安全或交易边界缺陷，立即停止后续付费轮次并关闭公网代理；不能把隔离库的旧结果当作正式云端通过。

## 顺序和具体检查

1. **恢复范围后的开工核对**：重读三份核心文档和本计划；重新核对实时 GitHub 主线、服务器项目身份、镜像、原库订单／供给摘要、备份哈希、代理确实关闭、2 GiB 主机内存／磁盘／OOM。沿用已核实的镜像与备份，不重新构建、迁移、导入或恢复原库。
2. **两名短时验收旅客**：先检查没有同名账户或凭证，再用服务器当前 Compose 支持的参数和既有账号管理镜像分别创建 A/B，凭证只写权限 600 的服务器私有目录，绝不打印密码。每次命令失败先查数据库和文件是否已经写入，再决定如何续跑，避免重复账号。完成后用真实公开 HTTPS 页面登录两者；未登录与错误登录分别拒绝，A 建立的会话 B 读取应返回 404。待生成卡后，再核对 B 无法读取 A 的卡；不通过 B 发送确认请求。
3. **原旅客行程和真实页面**：用已授权的原旅客账号只读核对有效机票、酒店及已取消历史的区分，确认页面和 API 与原库相同。浏览器在桌面与 375／338 像素检查登录后对话、行程、待确认卡和操作记录；刷新或切会话不能重复消息或混入别人的卡。验收账号密码不保存在聊天、截图或公开目录。
4. **约 12 轮真实对话，逐轮停机判定**：先从当前虚构供给只读选可售日期、具体航班和落地城市，不使用过期硬编码候选。样本依次覆盖：①普通问候；②航班查询且“先别下单”；③追问上一班当地出发／到达与报价、仍不下单；④明确预订该班，恰好一张机票待确认卡；⑤目的地酒店日期与房型只读查询；⑥明确选房预订，恰好一张酒店卡；⑦租车只读查询；⑧明确选车预订，恰好一张租车卡；⑨平台改签／取消规则问答，不冒充真实航司政策；⑩已取消历史与有效行程的区分；⑪同会话指代和记忆追问；⑫可达城市经典地点联网推荐，核对来源或明确降级。若某轮需要先补充日期／产品信息，允许助手澄清，但不得凭空选定或跳过确认。每轮记录响应、卡片类型与数量、会话归属、调用流水及前后订单摘要；出现未授权写入或误出卡立即停止。
5. **功能和资源终检**：确保所有待确认卡保持未确认，原旅客与验收账号业务订单摘要不变；临时账号停用，私有密码文件按已核对路径清理，测试会话与审计按规则保留。检查 2 GiB 主机内存、磁盘、容器／内核 OOM、代理／应用错误日志及密钥泄漏。再次核对 HTTPS、匿名登录页、未授权接口拒绝、内部路由 404、80／443 映射和 8000／5432 无主机映射。**通过后保持网站在线**，向旅客交付网址、授权账号使用方式、关站与重启命令及当前已知限制；结果写入独立验收记录和《当前进度》。

## 回退、端口与 Git 边界

- 如果认证、跨账号隔离、否定下单边界、未确认订单不变或凭证安全任一项失败，先关公网代理并保存脱敏证据；必要时停新应用，使用保留的旧镜像回退。原库不直接用旧备份覆盖，除非另有数据恢复计划和确认。
- 已有云防火墙 80、443、22 与 ICMP 规则；**不需要新增端口**。8000／5432 保持容器内部通信。SSH 22 当前对所有 IPv4 开放但使用密钥认证，来源收紧在本次上线稳定后单独规划，避免误锁远程管理。
- 使用现有专用 SSH 私钥、服务器私有配置和测试账号文件时只读取必要内容，不在聊天或 Git 记录值。验收完成后按已准备的[G-23 主线同步计划](G-23-云端验收记录合并与GitHub同步.md)同步公开计划和结果；OSS 每日自动备份仍属后续 P3.4c3c2，不阻断本次可用部署。
