# P3.1g2：行程简报、自然回顾与“周围”地点操作计划

> 制定日期：2026-10-23｜状态：用户已确认实施；结果详见《当前进度》。本文件只覆盖所列 P3.1g2 范围；不包含境外天气接入、正式库重置、`main` 合并或 GitHub 推送。

## 1. 目标与现状

本步修复用户真实连续对话里的三类断点：问“我现在有什么行程”时，简报只有航班号和起飞时间；问“我们前面说过了什么”时，未进入已有的会话回顾；明确自述“我在伦敦”后问“我周围有什么景点”时，未复用本会话所在地。同步澄清取消待确认卡与有效订单、旅客自述所在地与已确认航班出发地、配置的模型标识与实际底层版本之间的区别。

现有 `services/agent_reads.py` 的完整行程回答已有中文起终点和当地到达时间，但“最近／现在”的简报分支裁剪了这些字段；`graph_chat/controlled.py` 的回顾关键词缺少“说过了什么”等自然变体，附近识别只覆盖“附近／周边”，未覆盖“周围”。`memory` 节点有按本人会话读取待确认卡的基础，`location_context.current_city` 已由旅客自述保存。沿用这些边界，不建立无来源的长期个人画像。

## 3. 实施顺序

1. **统一当前行程简报**：让“现在／最近／接下来有什么行程”“我有航班要出发吗”均从本人仍有效的订单读取。机票主信息包括中文出发机场→到达机场、当地起飞与到达时刻和已确认状态，航班号保留用于核对；酒店给中文地点及入住／退房日期，租车给取车地点及当地取还时刻。简报按实际时间排序；列表有上限时明确“另有 N 笔”，并引导到“我的行程”页查看，不把省略项说成不存在。已取消和已结束订单只在明确询问历史时出现。
2. **扩展自然回顾**：用小而明确的问法集合覆盖“我们前面说过了什么／你还记得我想去哪吗／刚才聊到哪一步”等，不让普通“前面那班”错误转成回顾。只总结本会话的旅客自述位置、正在进行的航班／酒店／租车任务、已核对的候选和本人会话动作卡状态；任务内容可核对时才陈述。待确认卡说清“尚未改变订单”、逐张确认及卡片状态／有效期；已确认订单与待确认卡绝不混称。新会话或另一账号不带入旧回顾，模型不可用时仍能给出受控摘要。
3. **修复城市级‘周围’推荐**：把“周围／周围好看的地方／附近景点／周边游览”纳入同一受控地点判断。旅客刚明确自述在伦敦，且没有冲突的目的地锚点时，答复注明“按你本会话自述在伦敦”，再用已核查地点目录给伦敦城市级建议。若当前所在地与航班目的地都合理且不同，先问要查哪座城市；明确城市覆盖旧推断。没有坐标时不说“距离最近”“步行可到”；不从取消订单、另一会话、模型猜测或网页摘要推断当前位置。
4. **状态与透明提示**：在相关行程／回顾请求中区分待取消卡、已确认行程及已取消历史；只提示本会话仍待确认的卡，不将取消意图说成已取消，也不因聊天文字自动确认。若旅客自述伦敦，同时有即将从汉堡出发的有效机票，在相关出行安排询问中提示“出发城市与自述所在地不同，请核对前往出发机场的安排”，不推断一定赶不上、不自动改退。模型信息答复显示提供方及配置标识，并说明标识不能证明底层精确版本；不暴露密钥、服务地址或内部提示。
5. **页面呈现**：复用现有中文主信息和状态样式，检查对话中的行程简报、卡片提示以及“我的行程”桌面与窄屏布局；订单号放次级核对信息，不用长 ID 代替地点。必要时只改对应页面文案或样式，不改交易确认协议。

## 4. 验收矩阵与停机条件

| 场景 | 必须满足 |
| --- | --- |
| 两笔未来机票及酒店、租车 | 中文起终点／地点、当地起飞到达或入住取还时刻、已确认状态完整；长列表注明省略数 |
| 有已取消订单、两张待取消卡 | 普通行程不提已取消历史；回顾只称卡待确认，订单仍有效；明确问历史才列已取消 |
| “我们前面说过了什么”及近义问法 | 摘要只取本会话核实字段与本人卡状态；模型失联也可答；跨会话／跨账号不泄露 |
| “我在伦敦 → 我周围有什么景点” | 使用伦敦城市级目录及来源，注明自述依据；不编造距离、票价或营业时间 |
| 自述所在地与航班目的地冲突 | 对含糊的“周围”定向澄清；明确伦敦或明确落地目的地时按用户所指回答 |
| 自述伦敦但次日汉堡起飞 | 仅在相关出行安排中提醒核对接驳，不断言无法赶上，不生成任何取消卡 |
| 模型标识询问 | 给出配置标识及其含义边界，不泄露密钥或底层不可核实信息 |

先用用户原句和关键近义句做失败回归，再实施修复。通过新增针对性测试和完整现有测试，检查 Python 编译、页面脚本语法、依赖与差异；有页面变更时在隔离页面核对桌面及窄屏。任何未经确认写单、错人订单、取消历史混入普通行程、含糊地点被擅自确定、把待确认卡说成已取消，均阻断本步验收。记录测试数量、页面核对结果和未覆盖项；不为低风险文案重复收费联调。
