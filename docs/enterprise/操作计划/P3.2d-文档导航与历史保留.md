本步建议只建立清晰导航，**不批量搬动或删改历史文件**：三份核心文档保持固定路径，旧计划与验收记录保持原文和原日期；新增 `docs/enterprise/README.md` 作为文档入口，更新项目 README 与计划索引的入口说明。仓库根部的旧面试材料只标注为历史参考；它引用了已移除的旧代码，不能作为当前启动或开发指南。若以后确有必要物理归档，再单独给出文件清单、链接迁移和确认计划。
