1. 重读《产品需求》《软件架构》《当前进度》与本计划；检查 `git status`、提交图、`main...<历史功能分支>` 的文件清单。将 G-11 计划、索引和本次规划记录在功能分支单独提交；有来源不明的改动先查清，不混入合并。

3. 审阅租车改期归属和版本检查、原取车前截止、机场当地时间及 DST、产品日期窗、计费日和差额、确认复核、并发与幂等、旧 v2 卡失效、v011 与历史 v001～v010 完全不变。核对提交中没有 `.env`、密钥、原始 SQLite、数据库备份或验收状态文件，旧图路由仍不注册。
