# P3.4c2a 云端私有配置预检操作计划

> 2026-10-26。属于旅客已确认的 P3.4c 技术准备。本步不需要已购买服务器或域名，不读取本机正式 `.env`，不调用模型／搜索，不启动容器或开放公网。

## 目标

在云端镜像构建和空库初始化之前，用本机标准库检查专用 `data/generated/cloud.env` 的字段、域名形态、批次日期、固定镜像摘要、独立随机密钥与服务商密钥是否齐全。只输出通过／失败及字段名称，不输出任何密钥或密码值；避免配置错误到了容器启动才显现。

## 操作

1. 新增只读预检入口，限定只能读取 Git 忽略的 `data/generated/` 下的 `.env`；拒绝重复字段、测试模式、测试密钥、错误公开绑定地址和未固定镜像。Linux 上要求私有文件无组／其他用户读取权限。
2. 对部署域名、证书邮箱、数据库／JWT／初始账号随机值、演示批次日期、DeepSeek 与阿里云联网搜索参数作结构检查。最终域名由旅客确定后填写，本轮不生成或查看真实密钥。
3. 用虚构测试值做通过、缺字段、重复字段、泄露防护和错误目标测试；运行 Python 编译及差异检查。当前工作台无 Docker 时仅记录离线结果，不能代替真实服务器的 Compose、证书和连通验收。
4. 从当前本机 `main` 新建云端部署功能分支，更新云端操作指南与《当前进度》并在该分支提交；是否进入主线与 GitHub，按后续单独 G 计划复核同步。

## 失败处理

预检失败时先修正私有配置，不运行初始化；不得把 `.env`、密钥、密码或完整容器环境输出到聊天、日志或 Git。私有文件已存在时不能用配置生成器覆盖。
