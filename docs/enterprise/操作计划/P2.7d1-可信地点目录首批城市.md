# P2.7d1：可信地点目录首批城市操作计划

> 编写日期：2026-10-19｜状态：用户已确认，2026-10-20 在功能分支执行并验收；不授权主线合并或 GitHub 推送。结果见《当前进度》。

## 1. 起点、判断与目标

P2.7c 已覆盖 95 座可达城市的首次真实检索，并完成 60 页可读取来源的人工抽查。搜索结果会把酒店、城市页、榜单及描述性文章当作景点，也有地点实际上位于邻市和部分页面无法打开的情况。当前严格过滤后，仅 68/95 城市留有候选，低于已定的 75 城市验收线；联网推荐仍默认关闭。继续在标题过滤规则上堆例外，不能稳定证明地点与城市关系。

建议改为**版本化、人工核实的可信地点目录作事实基线**，实时搜索只发现候选或检查资料是否过时。第一小步先覆盖 30 座演示价值高且跨地区的可达城市，每城至少 2 个具体地点。对话仍是唯一展示入口，不做景点产品浏览或预订；不碰航班、酒店、租车交易规则。目录只保存公开地点资料，不保存旅客信息。

首批城市：Basel、Paris、Rome、London、Frankfurt、Amsterdam、Athens、Madrid、Istanbul、Copenhagen、Oslo；Beijing、Shanghai、Guangzhou、Chengdu、Hong Kong、Tokyo、Seoul、Singapore、Bangkok、Dubai、Jakarta、Manila；New York、Los Angeles、San Francisco、Chicago、São Paulo、Sydney、Nairobi。以上 30 座均在当前 95 城市航线范围内。

## 2. 待确认的实施步骤

1. **开工复核**：重读《产品需求》《软件架构》《当前进度》及本计划；核对功能分支、忽略账本、数据库边界和 `ALIYUN_IQS_ENABLED=false`。确认不会把未通过验收的 P2.7c 功能直接并入主线。
2. **目录模式**：为每个地点记录稳定 ID、城市和国家代码、规范名称及常见别名、类别、短介绍、来源页面与审查日期。城市／国家仍以现有机场映射校验。原始网页正文、票价、开放时间和未核实坐标不写入目录；每条来源标明场馆官方、政府／城市机构或其他可核实来源，不凭标题中的“官方”字样分类。目录变更可审查、可回滚。
3. **资料核对**：每城至少核实 2 个地点，优先场馆官方与公共机构页面；缺失时可用可信百科交叉核对。逐页实际打开，确认页面支持地点名称、所在城市／国家和所选主题，特别检查同名城市、邻市和中英别名。若页面无法打开或信息冲突，该条不入目录；记录失败原因。阿里云搜索可用于发现候选，但不能单独成为地点事实。
4. **对话接入**：已核实目录优先提供地点事实；用户偏好与本人行程只用于选择地点和组织介绍，模型不得创造目录外地点、票价、营业时刻或酒店距离。按用户已提出的“只作介绍”偏好，回答正文可只写地点和推荐理由；来源链接保留在 API 的结构化 `references` 供核查，页面是否展示链接留待简单页面阶段决定。实时搜索失败时回退至目录并说明资料审查日期；目录也无匹配时明确说无法核实。
5. **分层验收**：先做 5 座同名／跨语种高风险城市，再扩至 30 城市。固定测试覆盖错国、邻市、来源伪装、注入、过时信息、去重、无来源降级、跨账号和景点购买措辞。至少人工复核 60 条入库来源；30 城市每城至少 2 条可读且支持事实的目录条目。真实 DeepSeek 在隔离内存 API 抽测至少 10 组多轮推荐与交易意图切换，无错误交易卡、来源泄露或编造价格／距离。真实数据库重启只在隔离项目中按既有基线核验。
6. **收尾**：完整测试、两个演示日期、依赖、路由、公开差异与秘密文件检查通过；更新 README 和《当前进度》。只提交功能分支。30 城市通过后再给出 P2.7d2 的剩余 65 城市覆盖计划；P2.7 整体验收通过后，单独提主线合并与 GitHub 同步计划。

## 3. 调用额度与停止条件

本小步建议新增最多 **80 次 GlobalBasic 搜索、10 次 DeepSeek 请求**，与 P2.7b／c 账本分开，逐次预记并按 20 次搜索检查质量。网页人工核验不计入阿里云调用。GlobalBasic 单价仍未公开，人民币金额不能保证；实际账单由控制台核对。若出现服务限流、异常扣费、跨国错配或来源导致交易动作，立即停止相关批次，修复并复测；未达到 30 城市／60 条可靠资料时保持联网开关关闭，不宣称已完成 P2.7。

## 4. 需要用户确认的选择

确认后按本计划先做 **30 城市 × 至少 2 个可信地点**，再决定剩余 65 城市如何扩展；目录资料由我收集与核实，你不需要提供景点数据库。主线合并、GitHub 推送和实际开启联网推荐均不包含在本次确认内。
