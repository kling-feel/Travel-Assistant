## 合并、同步和核对

1. 获取最新远端 `main` 引用并与执行前快照核对。保持功能分支历史，不改写旧提交。
2. 切到本机 `main`，只执行快进合并 `feature/p34b-cloud-readiness`；若不能快进则停止，先查原因和冲突，不做自动解决。
3. 合并后核对 HEAD 与功能分支相同、工作区干净，检查关键测试、公开路由及本机入口。**本轮不重启或切换 8000／5436**；若本工作台无法访问该入口，记录为无法核实，不推断服务停止。
4. 仅执行普通 `git push origin main`，不强制推送、不改标签。随后独立读取远端 `main`，确认与本机 HEAD 完全一致。若推送被拒或网络失败，保持本机状态，报告差异并先查远端，不重复盲推。
5. 把合并与远端核对结果写回《当前进度》，必要时作一笔公开内容审查后的文档结果提交，并普通推送；不夹带后续云端部署或真实密钥。
