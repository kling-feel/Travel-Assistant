从 2026-10-17 起，每次进入新的实施阶段或执行会改变项目主线的 Git 操作，先读取《产品需求》《软件架构》《当前进度》，再在本目录建立一份独立计划。计划写明目标、范围、顺序、检查点、失败时的处理方式和 Git 影响；执行前向用户详细说明并取得确认。执行结果、测试结果及遗留问题统一写入《当前进度.md》，计划文档只保留事前方案。
