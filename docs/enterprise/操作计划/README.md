# 操作计划文档索引

先从[企业项目文档导航](../README.md)查看当前需求、架构、进度和[阶段验收记录](../README.md#验收记录)；本页保留全部事前计划，包括已完成或已撤回阶段。

从 2026-10-17 起，每次进入新的实施阶段或执行会改变项目主线的 Git 操作，先读取《产品需求》《软件架构》《当前进度》，再在本目录建立一份独立计划。计划写明目标、范围、顺序、检查点、失败时的处理方式和 Git 影响；执行前向用户详细说明并取得确认。执行结果、测试结果及遗留问题统一写入《当前进度.md》，计划文档只保留事前方案。

旧计划中的 `<历史功能分支>` 是公开文档整理后的阶段占位符。相关命令保留了当时的流程说明，不可直接复制执行；实际操作须依据当前 Git 引用重新核对并制定新计划。
