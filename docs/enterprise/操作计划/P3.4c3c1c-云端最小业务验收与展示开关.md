# P3.4c3c1c 云端最小业务验收与展示开关计划

> 2026-10-28 制定并经旅客确认；开工后旅客恢复完整验收范围，故本最小三轮方案**部分执行后暂停，未作为最终放行标准**，后续改按[P3.4c3c1d 完整计划](P3.4c3c1d-云端完整业务验收与在线发布.md)。承接[P3.4c3c1b 短时基础入口验收](../P3.4c3c1b-修复版短时基础入口验收记录.md)。本计划原拟只做证明云端能实际登录、对话、查询及安全生成待确认卡所必需的少量验证，并在通过后保持网站在线。

## 完成标准与当前状态

- 服务器为香港 2 vCPU／2 GiB；原 `travel-cloud` 数据库运行，修复版镜像已部署，应用与代理关闭。2026-10-27 虚构数据批次、五个原数据卷、证书、旧镜像回退标签和可解密的本机加密备份均已核对。当前本机／GitHub `main` 为 `1118b95`，发布文档在 `feature/p34c3c1b-release`。
- **本步通过**需同时证明：公开 HTTPS 登录页与授权账号实际登录；未授权访问被拒绝；真实 DeepSeek 对话能理解查询及“先别下单”，不生成待确认卡；旅客明确选择候选并说预订后恰好生成待确认卡，未点击确认前业务订单不变；一次联网地点推荐要么有可核验依据，要么清楚说明检索失败并回退；**验收后网站保持在线**。全部检查以当前正式云端应用和原项目完成，不用隔离库结果代替。
- 供给、订单、价格与付款始终为模拟；本步**不确认、不放弃任何交易卡，不执行真实支付**。对话样本限约 3 轮实际模型请求和 1 次联网推荐，以调用流水核对次数；若有明确缺陷，先停止扩展测试、保留日志并修复，不因轮数限制硬判通过。

## 操作顺序

1. **发布前只读核对**：重读《产品需求》《软件架构》《当前进度》和本计划；核对本机／实时 GitHub `main`、服务器身份、镜像 ID、数据库健康、五卷、证书与已加密备份哈希。只读比对原业务订单和供给摘要。确认当前无公网监听、主机有足够内存且无 OOM。若基线异常，停止启动并说明差异。
2. **只启动已有服务**：保留原数据库，按既有 Compose 项目依次启动应用与代理；不运行初始化、迁移、导入或镜像构建。先检查私有 `/ready` 和镜像 ID，再检查公开域名 HTTPS、登录页、内部接口被挡、80／443 正常。云防火墙已有 80、443、22、ICMP 规则，**不需要新增端口**；8000 和 5432 继续只在容器网络内。22 端口来源限制另列后续安全变更，本步不冒远程失联风险临时修改。
3. **最小授权验证**：用服务器私有方式创建一个短时授权验收账号，密码只保存在 Git 忽略目录，不发聊天；在实际页面登录一次，核对会话能保持、退出有效，未登录请求返回拒绝。临时账号与原旅客订单分离；本步不重复完整跨账号矩阵，依赖既有隔离验收并在结果中标明范围。
4. **三轮真实业务检查**：先从真实虚构供给只读选一条可售航线、日期和明确候选，避免硬编码已过期航班。第一轮旅客说“只查询，先别下单”，应展示候选而没有待确认卡。第二轮在同会话明确预订所选候选，应恰好生成一张待确认卡，但不点击确认；原旅客订单和验收账号业务订单都不变。第三轮提出可达城市经典地点推荐并要求联网，核对搜索使用记录、来源限制或明确降级，不把无法核实的信息冒充实时事实。记录响应、卡片数、业务订单摘要、错误日志和真实调用次数；若模型输出不符合安全边界，先关代理，保留证据并回退或修复。
5. **资源、日志与收尾**：检查 2 GiB 主机可用内存、容器／内核 OOM、磁盘、代理和应用错误日志以及密钥泄漏；停用临时账号，让未确认卡自然过期，不改原订单。再次核对原供给与订单摘要。验收通过后保持应用和代理在线，确认仅登录页对匿名访问可见、未授权接口拒绝访问，并给旅客明确的启动、关站和故障排查命令。所有结果写入独立验收记录及《当前进度》。

## 失败处理与协作

- HTTPS、登录或模型凭证不可用时，立即停止扩大请求；先读取脱敏日志和服务商调用状态。若存在越权、否定下单生成卡、未确认订单变化或密钥泄漏，先关闭公网代理，保留审计，按已留旧镜像回退；**不拿旧数据库备份直接覆盖原库**。此时网站保持关闭并报告具体阻断，不为满足在线目标放宽交易边界。
- 使用现有专用 SSH 密钥、服务器私有配置和已授权验收账号时只读取必要文件，不在聊天、公开仓库或截图打印秘密值。工作台若暂时不能发 SSH 命令，会准备可审查的本机脚本，只有确需旅客操作时才提供最短步骤。
- 本阶段不购买新服务、不新增防火墙端口、不配置 OSS。后续自动 OSS 备份依既定 P3.4c3c2 单独实施；正式业务验收完成后，再按独立 [G-23 主线同步计划](G-23-云端验收记录合并与GitHub同步.md)同步公开文档。
