## 当前费用估算

只作**本次首个购买周期**的预算敏感性检查，不是报价：若服务器首月仍为 ¥56、普通 `.com` 首年为 ¥85、异地备份首月预留 ¥5，则第一笔采购及首月备份合计约 **¥146**（服务器 ¥56＋域名首年 ¥85＋备份预留 ¥5）；其中域名按年一次支付，不能误写成“每月 ¥68”。4 GiB 按 ¥112／月的相同假设则约 **¥202**。具体域名和 Ubuntu 服务器订单价未核实，以上都不是可支付的最终报价。DeepSeek 和阿里云搜索调用费另列，不设置金额自动停机线；保持用量可见和异常提醒。用户设定的 ¥50～150／月是运行费用目标，本次包含域名年付时现金支出可能接近或超过 ¥150，需要在付款前明示。

## 购买前必须完成的逐项核对

1. 对旅客选择的 `tripfolio-lab.com` 只查可用性、普通词或溢价词、首年价格，不下单。
2. 在旅客阿里云中国站的最终服务器订单核对中国香港、2 vCPU／2 GiB／40 GiB、Ubuntu 24.04 LTS x86_64、1 个月、首购价、自动续费状态、网络及可能的税费。保留不含账号资料的报价证据。
3. 在 OSS 定价或预估页面选择异地地域、私有标准存储；列出存储、请求、流量与加密密钥管理成本。若密钥管理产生固定费用，先计入月预算再决定方案。
4. 把服务器＋域名首年一次支付＋异地备份的**首次现金支出**及本月运行费列给旅客；数据增长情景另列。超过旅客可接受的首次支出时先调整选型或预算。本轮不以未确定的续费价阻断短期部署。
5. 最终核对表包含商品、地域、镜像、期限、首购、域名、备份、自动续费状态和付款承担人。只有旅客确认这一张具体表以后，才进入购买与公网部署；不在聊天发送支付资料、登录密码、私钥或 API 密钥。

## 合规与恢复边界

阿里云[备案流程说明](https://help.aliyun.com/zh/icp-filing/basic-icp-service/user-guide/icp-filing-application-overview)写明香港节点无需工信 ICP 备案，但中国内地可访问的网站仍需按适用要求办理公安联网备案；正式开放前要据实际站点信息核对。单机快照不能代替异地加密备份。当前 8000 本机演示继续运行；本阶段不切换 5436 数据库、不导入真实旅客资料。

**部署配置差异**：本机 2 GiB 试验所用的 768／640／128 MiB 限额原先只保存在隔离试验覆盖文件中；现已单独加入可公开部署的 `compose.cloud.2g.yaml`，保留正式 80／443 端口。进入真实主机阶段仍要检查操作系统及 Docker 的总内存、OOM 和日志；不能误用仅绑定本机测试端口及内部证书的试验文件。
