## 实现与构建

- 新增应用 `Dockerfile`、白名单 `.dockerignore`、独立 `compose.container.yaml`，将 `backup`、`init` 放入显式 `setup` profile。普通启动只运行应用与数据库；数据库健康后启动应用，两个服务配置 `unless-stopped`。应用镜像以 `travel` 非 root 用户运行，日志写标准输出。
- 容器初始化只接受 `db:5432`、空库、迁移前 PostgreSQL 自定义格式备份及明确日期；完成 13 版迁移和脱敏虚构样本导入后，写独立清单。应用启动核对清单与数据库的日期、样本哈希、供给摘要、迁移版本。原 5436→8000 专用启动器未修改。
- `GET /health` 保持进程存活检查，新增 `GET /ready` 核对数据库可读且已初始化。镜像的地点推荐校验仍需 5.2 MB 交付虚构航线样本；这不是 `data/source/` 下的原始库。运行镜像实测约 444 MB、用户为 `travel`；`.env`、`.git`、`data/source/`、`data/generated/` 不在镜像内，页面资源与虚构样本在内。构建上下文约 6.02 MB，镜像内 `pip check` 通过。

1. `travel-p34a-db-1` 标签、独立 `travel-p34a_travel_pgdata` 挂载、健康状态与数据库端口未发布均已核对。首次初始化因把空库备份错误要求为至少 1 KB 而**在任何迁移／导入前停止**；实际空库自定义格式备份为 855 字节，`pg_restore -l` 可读、公共表数为 0。修正为检查文件存在和 `PGDMP` 格式后，复用该已核对备份完成初始化，没有重建或清理卷。
2. 新隔离批次日为 **2026-10-25**；13 版迁移、115 机场、33,121 航班、15,374 报价、618 可售航线、312 酒店房型、208 租车产品、2 个演示账号。8018 的 `/health`、`/ready`、`/app` 和页面脚本正常；付费模型和联网搜索在隔离配置中关闭，本轮新增付费请求为 0。
3. 两账号通过 8018 API 登录。本人航班、酒店、租车候选各生成一张待确认卡，生成时订单完全不变；确认一张酒店预订卡、拒绝一张机票预订卡、留一张租车预订卡待确认。另一账号读取会话或卡片返回 404。保存一条测试会话消息；最终隔离库为 1 个会话、1 条消息、3 张动作卡、1 个动作结果，原有机票订单数不变、酒店订单增加 1。
4. 分别重启应用、数据库、整个 Compose 项目后，重新登录与读取同一会话、三张卡状态和订单均成功。容器内向应用主进程发送终止信号后，Docker 重启次数从 0 增至 1，进程重新健康；重启前后的完整脱敏业务摘要相同。另一次 `docker kill` 属人工停止，观察到容器停下，按原项目命令恢复；不能据此宣称异常崩溃时总能自动恢复。Docker Desktop 整体退出、宿主机断电和旧 5436 曾退出码 255 的根因不在本轮证明范围。
5. 含验收交易的自定义格式备份 `p34a-after-actions.dump` 为 **687,425 字节**，SHA-256 `4D06EB58C9E86FA0060DACD43E7E58EFA6CA7D8A96DAA3519D9BF91393631002`；目录检查通过。它在第二个全新 `travel-p34a-restore_travel_pgdata` 卷实际恢复一次。恢复库与原库的日期、13 版迁移、17 类表计数、订单状态及订单／供给摘要**完全一致**；备份和摘要文件都留在 Git 忽略目录。

## 回归、风险和收尾

完整 **253 项自动化测试通过**（原 250 项加容器目标拒绝误写与数据库就绪检查），Python 编译、镜像内依赖检查、Compose 配置静态校验、Git 差异空白检查通过。详细启动、停止、备份和恢复命令已写入[项目 README](../../README.md)，脚本用途见[脚本索引](../../scripts/README.md)。当前仍仅是本地功能分支；云服务器、HTTPS、密钥托管、费用和公网访问另拟 P3.4b／c。

镜像已能从当前代码和依赖构建，但基础镜像使用可移动标签，`requirements.txt` 只固定直接依赖，传递依赖尚无单独锁文件。因此本轮证明了本机可构建和恢复，**不宣称跨时间的逐位相同镜像**；云端发布前应固定基础镜像摘要与完整依赖解析，并在隔离环境重建复验。

**收尾与提交边界**：工作台自动审批在读取镜像依赖清单时返回“使用额度已用完，无法完成自动审查”，明确说明不是认定操作不安全。旅客按核对过的命令在普通 PowerShell 停止了 `travel-p34a` 应用／数据库及 `travel-p34a-restore` 数据库；两个项目均无运行容器，原 5436 健康，8000 `/health` 返回 200。独立数据卷和忽略备份保留。当前代码及文档尚待一次**本地功能分支提交**，未合并 `main`、未推送 GitHub；G-19 发布仍须独立计划和确认。
