## 当前目标

- 数据库先在服务器端用恢复**公钥**加密，再经新加坡 OSS 公网 HTTPS Endpoint 上传。恢复私钥只由旅客在本机和密码管理器保存；密钥内容不进入仓库、聊天或服务器。
- 每天北京时间约 03:10 至 03:20 运行一次。成功后核对远端对象长度并保存本机状态；任务失败不得删除原卷或改变网站。

## 旅客在阿里云控制台的准备

1. 在 RAM 中创建仅供备份的用户，不开启控制台登录，只创建 OpenAPI AccessKey。上传身份只需对上述桶的专用前缀执行 `oss:PutObject` 和 `oss:GetObject`。后者只用于 `HeadObject` 元数据核对。策略内容已写入本机 Git 忽略文件 `data/generated/p34c3c2-ram-policy.json`，可直接复制到 RAM 自定义权限策略；不要授予 `AliyunOSSFullAccess`、删除对象、列整个桶或修改桶访问权限。
2. 将 AccessKey ID 和 Secret **只填到本机** `data/generated/p34c3c2-oss-config.json` 的对应两个空字段。该文件已被 Git 忽略。不要把内容、截图或密钥发到聊天。完成后只通知“已配置”。上传前程序还会核对目标地域、前缀和服务器私有文件权限。
3. 桶控制台的生命周期规则仅匹配 `travel-assistant/backups/`，按对象最后修改时间满 30 天删除，其他路径不适用；版本控制保持关闭。规则创建后还需核对生效状态。OSS 生命周期任务可能延后执行，不能把它当作精确到分钟的删除器。[阿里云生命周期说明](https://help.aliyun.com/zh/oss/user-guide/overview-54/)。

## 安全边界

备份上传采用不覆盖同名对象的参数，且每次使用新的时间戳与随机后缀。OSS 中保存的是 `age` 密文；明文导出、批次清单和临时打包文件只在服务器受限临时目录存在，流程结束自动移除。密文对象会附带 SHA256 元数据，备份程序保存对象名、长度和哈希的非敏感状态。OSS RAM 上传身份无删除和桶管理权限；恢复下载不复用服务器端的长期上传密钥。
