## 短时公网与页面

- 只在私有就绪通过后启动原代理。Windows 工作站直连服务器并校验证书：`https://adzyforever.com/app` 以 GET 返回 200、TLS 验证成功；HTTP 返回 308 到 HTTPS；`www` 的 HTTPS 返回 301 到根域；公网 `/ready` 与 `/openapi.json` 均返回 404。匿名打开登录页，没有输入账号、发送对话或调用付费模型／搜索。
- 用浏览器设备视口准确设为桌面 1440、手机 375 和 338 像素，三种宽度均显示账号、密码、按钮与说明；`documentElement.scrollWidth` 和 `body.scrollWidth` 分别等于对应视口宽度，无横向溢出。普通无设备模拟的窄窗口截图曾出现裁切，准确设备视口复核排除了页面溢出。截图仅保存在本机 Git 忽略目录。
- 独立 Windows 网络对 80／443 有可用 HTTPS 响应；对 8000／5432 的直接 HTTP 探测在 5 秒内无应用响应。一次原始 TCP 建连探测却报告这两端口可连接，与服务器 `ss` 只监听 22／80／443、Docker 只为代理映射 80／443 的结果不一致。旅客随后发来的云防火墙截图中**可见** 80、443、22 与 ICMP 四条已启用规则，未见 8000／5432；截图底部还有未显示完整的一行，已请旅客补下半部分或总条数。因此公网 8000／5432 隔离项尚未完整核证。当前公开服务已关闭。
