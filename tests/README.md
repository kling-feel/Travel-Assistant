# 自动化测试导航

从项目根目录运行完整回归：

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -p 'test_*.py' -q
```

| 目录 | 覆盖范围 |
| --- | --- |
| `business/` | 本人订单、航班与产品、报价、确认事务、数据清理 |
| `dialogue/` | 多轮对话、提案、记忆、候选、取消、流式回合 |
| `recommendations/` | 可达城市、地点目录、证据来源与推荐 |
| `interface/` | 页面、中文展示、页面旅程、调用计量 |
| `support/` | 仅供页面测试使用的固定模型与内存应用辅助代码 |

每组可用相同的 `unittest discover` 命令单独运行，例如把 `-s tests` 改为 `-s tests/business`。完整回归以根目录命令为准；测试使用内存数据库、固定模型和离线样本，不需要正式 PostgreSQL 或付费 API。真实数据库专项核验位于[脚本入口索引](../scripts/README.md)，运行前须先核对其数据读写边界。

现行测试之间仍有用于复用固定模型／构造数据的导入。目录整理保留原有 230 次测试执行和 224 个不同测试签名，其中 6 次是原先导入完整测试类造成的重复执行；后续若要消除重复，应先把共享辅助代码独立出来，再更新测试基线。
